# Дом в Порядке — чат-бот в MAX для управления домом

**Трек:** Умный город
**Организаторы:** Минобрнауки + MAX
**Дедлайн:** 29 сентября 2026
**Версия:** 1.0.0 (<commit-hash>)

---

## 1. Назначение решения

Жильцы многоквартирных домов и частного сектора тратят время на поиск своей управляющей компании (УК), не знают, кого вызывать при аварии, и не могут отследить статус обращения. Мы делаем чат-бот в MAX, который за 30 секунд ведёт жильца от адреса до поданной заявки: определяет УК по адресу, оформляет аварийную заявку или заявку на мастера, показывает контакты диспетчеров и УК, ведёт заявку до закрытия и ежемесячно напоминает о возможности вызвать мастера.

**Основная ценность:** сократить путь от проблемы (потоп, нет света, сломался кран) до поданной заявки в УК, и решения существующей ситуации.

---

## 2. Основной пользовательский сценарий

### As Is
- Жилец ищет УК по адресу в интернете / на квитанции.
- Звонит в диспетчерскую, часто не дозванивается.
- Не знает номер аварийной службы при утечке газа.
- Статус заявки непрозрачен.

### To Be
1. Жилец открывает бота `t443_hakaton_max_bot` в MAX и нажимает `/start`.
2. Выбирает роль (собственник / арендатор).
3. Вводит адрес (город, улица, дом) → подтверждает.
4. Бот находит УК по адресу → жилец выбирает из списка.
5. Профиль сохранён → главное меню.

### Сквозной сценарий «Авария»
1. `🚨 АВАРИЯ` → квартира → категория (например, `💨 Утечка газа`).
2. Бот создаёт заявку, показывает **карточку с диспетчерами** («Диспетчер газа: 04 / 104», «Служба спасения: 112») и кнопки «📤 Отправить заявку в УК», «✅ Пропустить имя».
3. Жилец вводит имя (или пропускает) → «Ваше заявление отправлено диспетчеру».
4. Главное меню.

### Просмотр и завершение
- `📋 Мои активные заявки` → карточки с УК, статусом, кнопка «✅ Завершить аварию #N».
- Подтверждение → `CLOSED`, `closed_at=now()`.
- `📊 Статус всех заявок` → список с ✅/⭕ по каждой заявке.

### Частный сектор
- Если по адресу УК не найдены → кнопка «🏘️ Частный сектор».
- Профиль сохраняется без УК. При авариях/мастере квартира не запрашивается.
- Жалоба сообщает: «У вас не привязана УК (частный сектор)».

## 4. Запуск всех компонентов

Одна команда:

```bash
docker compose up -d --build
```

Проверить статус:

```bash
docker compose ps
curl -s http://localhost:8081/api/v1/health
# {"status":"ok"}
```

Пересборка с нуля (удалить данные, БД, Redis):

```bash
docker compose down -v && docker compose up -d --build
```

Остановить:

```bash
docker compose down
```

Остановить и удалить все данные:

```bash
docker compose down -v
```

## 8. Работа с данными

- **PostgreSQL** — основное хранилище.
  - `buildings`, `users`, `emergency_alerts`, `service_requests` — V1
  - `management_companies` (25 224 шт) — V2–V4
  - `max_users` — V3
  - Статусы + `closed_at` — V5
  - `uk_id` в заявках — V6
  - `last_ping_at` — V7
- **Redis** — FSM и профили:
  - `fsm:state:{chatId}` — текущее состояние
  - `fsm:temp:{chatId}` — временные поля (адрес, квартира, flow)
  - `fsm:last:{chatId}` — последний id заявки
  - `profile:{chatId}` — сохранённый профиль

## 10. Пошаговый сценарий проверки

1. Открой бота `t443_hakaton_max_bot` в MAX, нажми `/start`.
2. Выбери «🏠 Я собственник».
3. Введи адрес: `Ижевск Ленина 90` → «✅ Да, верно».
4. Выбери УК из предложенного списка.
5. В главном меню → `🚨 АВАРИЯ` → введи `78` → `💨 Утечка газа`.
6. Убедись: пришло сообщение с диспетчером газа и «Служба спасения: 112».
7. Введи имя `Софья` (или «Пропустить»).
8. Меню → `📋 Мои активные заявки` → найди карточку заявки, у неё правильная УК.
9. Нажми «✅ Завершить аварию #N» → «✅ Да, завершить» → «Заявка #N завершена».
10. Меню → `📊 Статус всех заявок` → заявка помечена ✅.
11. Меню → `🔄 Начать заново` → адрес `деревня Гадюкино` → «🏘️ Частный сектор» → профиль без УК.
12. Меню → `🚨 АВАРИЯ` → **сразу** меню категорий (без вопроса про квартиру).
13. Меню → `📝 Подать жалобу в управляющую компанию` → введи текст → сообщение про частный сектор.

## 11. Ожидаемое поведение

- Все тексты на русском.
- Inline-кнопки в 1–2 колонки.
- При аварии: карточка диспетчера + кнопки.
- После `/start` в любой момент — возврат в главное меню.
- УК в карточке заявки совпадает с УК, выбранной при регистрации **на момент создания заявки**.
- Ошибки не ломают FSM: `try/catch` + fallback «Не понял команду. /start».

## 12. Известные ограничения

1. Реальные интеграции с УК отсутствуют. Данные тестовые.
2. Автоматической смены статусов (`SENT_TO_UK`, `IN_PROGRESS`, `PENDING_CONFIRM`) нет — диспетчер УК должен выставлять их через REST API.
3. Жалоба в УК — заглушка (сообщение пользователю без реальной отправки).
4. Архив закрытых заявок в MVP доступен только через `📊 Статус всех заявок`, отдельного экрана нет.
5. Cloudpub — публичный туннель, не production-grade. Может отваливаться при длительной неактивности.
6. Работаем с одним ботом (`t443_hakaton_max_bot`), без multi-tenancy.
7. Часовой пояс — локальный системы (MSK).

## 13. Порядок остановки и повторного запуска

**Остановить, сохранить данные:**
```bash
docker compose down
```

**Запустить снова:**
```bash
docker compose up -d
```

**Полный сброс (удалить всё):**
```bash
docker compose down -v
docker compose up -d --build
```

**После изменений в коде java-core:**
```bash
docker compose build --no-cache java-core
docker compose up -d
```

**После изменения миграций V1–V4:** обязательно `down -v` — Flyway не даст изменить уже применённые checksums.
